# PBO-Java-Smt-3

Object-Oriented Programming (Pemrograman Berorientasi Objek / PBO) coursework and practical lab implementations for Semester 3.

## Structure
- `Praktikum/`: Core Java OOP exercises covering Association, Aggregation, Composition, Encapsulation, and Java Collections Framework (`ArrayList`, `HashMap`).
- `RentalMobil/`: Vehicle rental management system exercise.
- `SistemAkademik/`: Academic information system modeling exercise.

## Requirements
- Java Development Kit (JDK 17+ or compatible)

## How to Compile & Run
Navigate to the root directory and compile individual modules:
```bash
javac Praktikum/Bengkel.java
java Praktikum.Bengkel
```

## Environment Variables
None required.
